# Prototipo v1 (Base44) — documentos históricos

Estos documentos describen el **prototipo v1** construido sobre Base44 (React + Vite), no el código Next.js actual.
**No son normativos**: si contradicen al repo, manda el repo, y para el sistema vigente hay que leer `docs/01`–`docs/09` y `docs/estado/`.
Se conservan como antecedente de la tesis: de aquí salieron los módulos, los portales y el formulario del expediente.
Ya se ajustaron al cambio de alcance de octubre de 2026 (sin psicología), pero los nombres de entidades y componentes siguen siendo los del prototipo.
