# Origen de los logos de universidades

Imágenes que identifican a cada universidad dentro del portal (son sus marcas;
se usan solo para eso). Se cargan con `scripts/cargar-logos-universidades.ts`.

| Universidad | Archivo | Origen |
|---|---|---|
| UCATECI | `ucateci.png` | favicon oficial de ucateci.edu.do (192 px) |
| UNPHU | `unphu.jpg` | Wikimedia Commons «Logo-unphu.jpg», CC BY-SA 4.0 (sus sitios oficiales bloquean la descarga automática) |
| UTESA | `utesa.png` | utesa.edu (`logo2024.png`) |
| UASD | `uasd.png` | Wikimedia Commons «Universidad Autonoma de Santo Domingo.svg» (miniatura PNG), CC BY-SA 4.0 |
| PUCMM | `pucmm.png` | pucmm.edu.do (`logo-pucmm-color.png`) |

Las dos de Commons exigen atribución (CC BY-SA 4.0); si algún día se publican
fuera del portal interno, conviene reemplazarlas por las oficiales.
